## Cadence rules

| Cadence | Cycle | Notes |
|---|---|---|
| Battle Pass seasons | 60 days each | LOCKED — no skipping. Players expect rhythm. |
| Major content drops | ~90 days | Chapter content, race expansions, Tower variants |
| Polish patches | Monthly | Bug fixes + QoL only — no major mechanics changes |
| Weekly events | Weekly | Wednesday Chest tier celebrations, weekend tournaments, friend referral bonuses |
| Daily | Always-on | Daily mission rotation, login streak, Tower availability |
